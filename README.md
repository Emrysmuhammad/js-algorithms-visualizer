# AlgoViz - Algorithms Visualizer

Interactive learning platform for JavaScript algorithms and data structures.

## Features

- **Sorting Algorithms**: Bubble Sort, Merge Sort, Quick Sort, Heap Sort
- **Searching Algorithms**: Linear Search, Binary Search
- **Data Structures**: Stack, Queue, Linked List, Binary Search Tree
- **Interactive Visualization**: Watch algorithms in action
- **Performance Metrics**: Track comparisons, swaps, and execution time
- **Adjustable Speed**: Control animation speed
- **Customizable Size**: Change array size for visualization
- **Big O Complexity Chart**: Reference guide for algorithm complexity
- **Fully Responsive**: Works on all devices

## Getting Started

1. Clone the repository
```bash
   git clone <repository-url>
   cd js-algorithms-visualizer
```

2. Open `index.html` in a modern browser

3. Choose an algorithm and click "Visualize" to see it in action

## How It Works

- Select a sorting or searching algorithm
- Adjust visualization speed and array size
- Click the button to start the visualization
- Watch as the algorithm sorts or searches the data
- View real-time metrics for comparisons, swaps, and time

## Algorithms Included

### Sorting
- **Bubble Sort**: O(n²) - Simple but slow for large datasets
- **Merge Sort**: O(n log n) - Efficient divide-and-conquer approach
- **Quick Sort**: O(n log n) average - Fast in-place sorting
- **Heap Sort**: O(n log n) - Consistent performance

### Searching
- **Linear Search**: O(n) - Sequential search through array
- **Binary Search**: O(log n) - Fast search on sorted arrays

### Data Structures
- **Stack**: Last-In-First-Out (LIFO) collection
- **Queue**: First-In-First-Out (FIFO) collection
- **Linked List**: Dynamic collection with node-based structure
- **Binary Search Tree**: Ordered tree structure for efficient operations

## Learning Tips

1. Start with Bubble Sort to understand basic sorting
2. Compare different algorithms with the same dataset
3. Observe how execution time changes with array size
4. Use the Big O chart to understand complexity trade-offs
5. Experiment with different speeds to see algorithm mechanics
